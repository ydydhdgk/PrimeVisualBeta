Useful Visuals - Forge 1.16.5 (клиентский мод)

Сборка:
1. Скачайте MDK Forge 1.16.5 (files.minecraftforge.net) и скопируйте из него
   gradlew, gradlew.bat и папку gradle/ в эту папку.
2. Нужна JDK 8 (или новее - Gradle сам найдёт 8 через toolchain).
3. ./gradlew build   -> jar в build/libs/
   ./gradlew runClient -> тестовый запуск

Управление: C - зум (колесо мыши при зуме меняет силу; кнопка переназначается в настройках).
